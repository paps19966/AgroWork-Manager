# AgroWork Manager

AgroWork Manager is a complete Android application for farm and employee management.  
It was developed as my Bachelor's Thesis project.

## ⭐ Features
- Employee work hour tracking
- Individual salary calculations
- Multi-worker tasks with custom rates
- Filtering by date range
- Calendar view with color-coded work types
- Detailed reports per employee
- PDF export (hours, payments, comments, total amounts)
- Firebase Authentication
- Firestore real-time database

## 🛠 Tech Stack
- **Java**
- **Android Studio**
- **Firebase Authentication**
- **Firestore**
- **XML layouts**
- **RecyclerView adapters**
- **Custom dialogs**
- **PDF generation**
